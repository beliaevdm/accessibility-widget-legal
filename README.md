# Legal pages of the Wix apps by Dmytro Bieliaiev

GitHub Pages (Jekyll, theme minima): https://beliaevdm.github.io/accessibility-widget-legal/
(the repo keeps its old name — the URLs are already in Dev Center listings and app dashboards).

- `_layouts/privacy.html` — every privacy page: sections 1–2 (`_includes/privacy/intro.md`), the app's own
  sections 3–6 (the page's content), sections 7–15 (`_includes/privacy/common.md`), change history (front matter).
- `<app>-privacy.md` — one per app, from `_templates/app-privacy.md`; `apps-privacy.md` — the general policy
  (Company Info link of the shared Wix business account); `index.md` — all apps with Privacy / Terms links.
- `apps/<app>/img/` — listing images; `assets/` — shared images (developer logo).

Process and checklist: `docs/PRIVACY-POLICY.md` in the wix-apps repo.
