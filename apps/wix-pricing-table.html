Pricing and comparison tables for Wix, without code

Show your plans clearly and let visitors compare them at a glance.

Two layouts

  • Pricing cards: price, suffix (for example /mo), badge such as Most Popular, and a call-to-action button per plan.
  • Comparison grid: rows of features with yes/no or text values per column.

Set up

  1. Install Pricing & Comparison Tables.
  2. Create a table in the dashboard: columns, rows, prices, buttons.
  3. Add the Pricing Table widget in the Editor and choose your table.

Tips that improve clarity

  • Highlight one recommended plan.
  • Keep feature rows short and comparable.
  • Use one clear action per plan.
