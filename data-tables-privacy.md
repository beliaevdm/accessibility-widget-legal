## 3. Information the app processes

**Tables added by the site owner:** the rows and columns the site owner types, pastes, imports from a file or links
from a shared online sheet, and the table's settings (column types, layout, theme, colours and texts).

**Linked sheets:** if the site owner links a sheet or CSV file by its address, the app's server downloads that file
to refresh the table. The address is stored with the table and is **never sent to visitors**; columns the site owner
hides are not sent to visitors either.

**Visitors:** the app has no forms and collects **no personal data from visitors**. Searching, filtering and sorting
happen in the visitor's browser and are not recorded.

## 4. Cookies and browser storage

The app **does not set any cookies**. In the visitor's browser it uses `sessionStorage` to keep a copy of the table for faster loading; it is
cleared when the tab is closed. In the site owner's dashboard, `localStorage` remembers whether a short review request was already shown.

## 5. Third-party services

The app uses **no analytics, tracking or advertising services** of its own. From visitors' browsers it loads only images the site owner puts in image columns. Links in a table
open only when a visitor clicks them. A linked sheet is fetched by the app's server from the address the site owner
gave; that provider's own terms apply to the sheet.

## 6. How long data is kept, and how to delete it

Tables stay in the site's Wix collections until the site owner deletes them in the app dashboard or in the site's CMS. Removing
the widget from a page does not delete the table.
